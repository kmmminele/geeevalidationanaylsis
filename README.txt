Analysis Code for:
Longitudinal Validation of the Generic Rating Scale for Previous Treatment Experience, 
Treatment Expectations, and Treatment Effects (G-EEE) in Endometriosis Patients

This repository contains the R code used for the analyses reported in the manuscript "Longitudinal Validation of the Generic Rating Scale for Previous Treatment Experience, 
Treatment Expectations, and Treatment Effects (G-EEE) in Endometriosis Patients".

The repository contains analysis code only. Code used solely for formatting results for tables and figures is not included.
The data used and/or analyzed during the current study are available from the corresponding author upon reasonable request.

R-Version: 4.4.2
